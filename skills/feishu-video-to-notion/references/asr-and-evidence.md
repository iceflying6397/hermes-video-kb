# 语音转写与证据

优先取与已确认内容 ID 对应的页面公开文字稿；没有文字稿时，固定助手从当前笔记对象发现 MP4／M4A，核验后下载、解码并调用本机 faster-whisper。不能把找到媒体地址或模拟返回文字当作实际 ASR 成功。

复用已有运行组件、small／base／tiny 缓存权重和 ffmpeg／ffprobe；缺少时说明具体需要后准备，任务保留。不自动下载模型、不改用云端识别、不把 GPT 订阅当音频 API 额度。可选安装器 `--with-local-asr`（这份可选依赖要求已有 Python 3.12+，不自动升级系统 Python） 安装约 60–85 MB 固定组件，不含权重。

上限：256 MB、20 分钟媒体，3 分钟下载，90 秒音轨处理，5 分钟识别及 CPU 限额，5 万字符正文。标为“ASR 转写，非官方字幕”；音轨时长不匹配、超长截断都说明并标局部。处理完整音轨不等于逐字准确，沉默也不能直接证明覆盖完整。

页面文字稿未证明覆盖全部声音时如实保留限制。配文、标题、OCR 和转写不能混称；目前没有 OCR、HLS／DASH 或浏览器渲染后备。真实验收要抽查讲话的不同位置。

手工字幕是用户主动提供时的补充，不替代只发链接的主要流程。只有元数据时不编造正文摘要。
