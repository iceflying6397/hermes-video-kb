# 初始化与升级

2.1.0 是测试候选版，代码已接入受限公开媒体、本地 ASR 与原生 GPT 订阅摘要，但完整真实流程仍需验收。不要沿用旧版“没有 ASR”的说明，也不要提前宣布修复完成。

Hermes 核验固定候选包，先运行安装预览、说明位置及影响，再执行已经授权的安装。安装器管理本 Skill 的独立环境及旁边的私有锁、恢复记录，不修改其他 Skill、全局模型或审批。

优先复用已有模型和本地识别条件。若缺 faster-whisper，可在说明后使用 `--with-local-asr`（这份可选依赖要求已有 Python 3.12+，不自动升级系统 Python） 安装约 60–85 MB 固定组件；不含模型权重，后续升级继承该选择。权重／ffmpeg 若缺，先核实具体下载与资源需求并集中说明，不能默默新增服务。

随后 `setup` 检查模型和 ASR。`ready_to_connect` 只表示摘要兼容，不保证识别就绪；分别查看 `transcription`。兼容后说明 Notion 官方权限，再按已有连接意图执行 `setup --connect --open-browser`，由用户官方确认。有效绑定复用，无绑定才建库。

连接、视频获取、转写、订阅整理和完整保存逐步验收。用户只需发链接，手工字幕是补充；失败说清具体层级，保留状态并继续可独立完成的部分。

升级先保护未知同名 Skill 和用户修改。中断时同一安装命令重试，由安装器恢复；并发时等待。不手工删锁、恢复记录、队列或旧运行目录。既有绑定和任务保留，未知写入先核验，不重新创建。
