# 测试候选包与恢复

版本：**2.1.0 测试候选版，按用户要求上传 GitHub 供安装实测，没有部署服务。** 已有媒体／ASR／订阅接入代码不等于完整真实验收通过；最新证据见[验收状态](acceptance-status.md)。仅官方登录成功或模拟测试通过，都不能作为正式发布依据。

无需作者服务器或自建 OAuth 应用，使用 Notion 官方远程 MCP。安装器面向 macOS／Linux 和已有 Python 3.11+；Linux 未实机验收，Windows 暂不支持，不自动安装系统 Python或接受软件许可证。

在源码目录通过相应检查后构建新的本地候选包，保留旧包：

```text
python scripts/build_release.py --output dist/hermes-video-kb-2.1.0-rc.1.zip
```

构建器按白名单生成 `RELEASE_MANIFEST.json`、候选包和校验值，排除授权、个人状态、模型密钥、媒体、识别权重、测试材料与开发环境。基础依赖固定于 `requirements.lock`，可选 ASR 依赖单独锁定版本和下载哈希。文件哈希可发现内容变化，不等于作者身份签名。每次修改发布文件后重新构建清单。

## 安装与升级

安装器提供 `--dry-run`、`--python`、`--skills-dir` 和可选 `--with-local-asr`（这份可选依赖要求已有 Python 3.12+，不自动升级系统 Python）。ASR 选项约下载 60–85 MB 固定组件，不含权重／ffmpeg；优先复用已有条件，额外下载先说明。已启用的本地 ASR 选择在升级时继承，不因普通升级丢失。

安装拒绝覆盖未知同名 Skill或用户修改，运行目录按版本和依赖选择独立保存；激活前校验文件和依赖。并发由私有锁阻止，中断由持久恢复记录接续；预览只报告，不恢复。遇到冲突保留现场，不手工删锁或恢复记录。

旧运行版本和任务状态应保留。安装中断由同一安装命令自动恢复；功能回退与中断恢复不同，当前没有一键切换旧运行版本的命令，直接重跑旧包可能因已存在的版本目录而停止。不要删除目录、改标记或删队列来强行回退。源码回退应使用本次同步前的完整备份，先核对之后是否有用户修改，再逐项恢复；Notion 笔记、授权和任务状态不随源码回退。旧版本缺少本轮功能，只用于故障恢复，不是功能等价方案。

## 正式版发布前仍须验证

真实平台入口和来源归属、真实视频不同位置的讲话、无原生字幕时实际下载／ASR、现有 GPT 订阅整理、官方 Notion 建库／绑定／完整正文和尾部回读、重复与未知写入恢复、干净安装和升级都要分别有证据。抖音、小红书、公众号逐项列出已验证与未验证，不能用一个替代样例冒充其他平台通过。

本次上传依照用户后续的明确要求，保留测试候选定位。安装必须使用当前候选包并核对校验值；需要固定来源时使用对应提交的链接，不以旧包或后续变化的分支内容冒充本次版本。上传不会将未完成的验收项目变为通过。
