# 常见问题

**没有服务器，能用吗？** 连接走 Notion 官方服务，处理程序随本地 Hermes 运行，不需要租服务器或维护作者中转。

**需要发送密钥吗？** 不要。Notion 只在官方页面确认；模型沿用 Hermes 中已配置的 API 或订阅，不让用户把密钥、令牌、Cookie、授权码或完整配置贴进聊天。

**为什么 Notion 权限比知识库更广？** 官方连接可能覆盖工作区其他可访问内容。助手只提供专用库固定操作，但无法缩小令牌本身的授权范围。授权前会解释，介意时可选独立工作区。

**提示 Notion 授权已失效，重新连接也没有弹出授权页。** 先让 Hermes“断开 Notion”，再“连接 Notion”，在官方页面重新授权。断开只清除本机连接凭据，保留已有笔记、知识库绑定和待处理队列；请选回原来的账号与工作区。重新连接后先“继续处理没完成的链接”，核对可能已经保存的内容，不删除队列或重复创建。程序不会因为收到授权失效响应而自动重试写入或自动授权。

**视频为什么仍只有简介或书签？** 本版已实现本地转写，但现有公开页面可能没有支持的文字稿或直连媒体。浏览器渲染／资源发现、HLS／DASH 尚未实现，不能保证所有视频可读。助手应说明实际取得什么，不能把收藏说成视频处理完成。

**提示缺少本地识别条件。** 让 Hermes 查看 `doctor`，一次说清是缺识别组件、缓存权重还是 ffmpeg／ffprobe。可选 `--with-local-asr`（这份可选依赖要求已有 Python 3.12+，不自动升级系统 Python） 约下载 60–85 MB 固定依赖，不含权重；其它下载先查明大小和影响。不会自动改成云端收费识别，也不要求日常手工交字幕。

**GPT 订阅是不是不支持？** 现在已接入 Hermes 原生 `openai-codex / codex_responses`；预检和实际摘要都走该路径。真实登录过期或限流时需恢复原登录／等待，正文保留，不切换付费 API。其它 Responses、自动选择和外部进程模式尚未承诺支持。预检通过不等于真实账号调用成功。

**提示网络地址不是公网，但浏览器能打开。** 可能是代理 fake-IP，也可能是真正非公开地址，不能直接关闭防护。Hermes 先诊断；确认为 `198.18.0.0/15` 后，可说明并经同意启用当前助手的 Cloudflare 公共 DNS 核验。只发送访问域名，不送链接参数或正文；仍拒绝私网和非预期跳转，随时可关闭。

**提示保存结果待确认。** 先“继续处理没完成的链接”，已有候选位置会只读核对完整内容，不重复创建。没有位置才需提供 Notion 页面链接。正文缺段、读回截断或旧任务已无本地原稿时，保留状态，不宣称成功或删记录重建。

**提示原文已保留、摘要暂未生成。** 尚未写入 Notion。稍后继续会复用原文；达到三次上限后，明确要求“再试这一个任务”。完整保存确认后才清理正文。

**重复发送旧书签会自动补成转写吗？** 不会。当前重复来源返回旧笔记，不覆盖已有内容，也不能把新取得但未保存的文字说成远端已有。旧版未做完整正文核验的记录会保留这项限制。

**我自己有字幕文件。** 可明确给出 TXT、SRT、VTT 和对应链接，作为独立补充笔记（最多 5 万字符）。这只是补充，不是日常自动视频流程的前提，也不会搜索其他本机文件。

**平台拒绝读取，Notion 里也没有书签。** 抓取失败时只保留本机任务。只有成功取得页面信息才可能按证据保存；不循环绕过登录或验证码。

**手机点击首次授权失败。** 首次 Notion 登录须在运行 Hermes 的电脑浏览器完成。之后可以从已有飞书私人对话发链接。

**安装中断、同名目录冲突或并发安装。** 中断重跑同一命令，安装器先恢复；另一项安装仍在运行就等待。未知 Skill、用户修改或异常恢复记录会保留，不强行删除。升级不删除旧版本、绑定或队列。

**想检查或停止。** “看看知识库是否正常”运行 `check`，只读核验远端；`status` 看本机状态；`doctor` 看模型和 ASR 条件。暂停保留连接，断开清除本地授权，都不删除笔记。完整撤销在 Notion 设置操作。
