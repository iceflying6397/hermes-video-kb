# 安全与隐私

## 授权前说明

安装添加本 Skill、固定依赖、独立运行目录及旁边的私有锁与恢复记录。可选本地 ASR 组件（安装需已有 Python 3.12+，不自动升级系统 Python）约需下载 60–85 MB，不含识别权重。先说明实际用途、位置、数据去向、费用／下载／资源影响及停止方法；已有授权范围内的日常处理不反复确认。

Notion 官方授权可能覆盖所选工作区其他可访问内容，助手固定操作范围不等于官方最小授权。程序不提供任意 Notion 请求、删除、移动或改写无关笔记的入口。

这些保护不隔离整个 Hermes，也不是系统钥匙串。同一系统用户有权限的程序仍可能读取本地凭据，Skill 不能取消宿主原本的电脑操作能力。不要关闭 Hermes 审批或开启全局自动放行。

## 数据去向

| 数据 | 接收方与用途 |
|---|---|
| 来源 URL、公开页面请求 | 对应内容平台；必要分享参数仅用于访问 |
| 来源页面中的媒体地址 | 对应平台允许的媒体域名；取得同条视频音轨 |
| 下载的音轨 | 本机解码和 faster-whisper；不会自动上传云端识别服务 |
| 已取得的正文／转写和摘要请求 | Hermes 当前已配置模型；订阅方式只向 ChatGPT 官方目标发送 |
| 摘要、观点、来源、正文 | 已绑定的 Notion 专用知识库 |
| 可选公共 DNS 查询 | 默认关闭；获准后仅代理 fake-IP 情况向 Cloudflare 发送公开域名，不发送路径、查询参数、正文或凭据 |

Notion 凭据不进入摘要输入、聊天或第三方代理。模型只返回受限结构化文字，没有工具，不选择保存目标。本项目不维护作者中转服务器。

本机保存授权、绑定和处理队列，不同 Hermes 配置相互区分。正文在待摘要、待保存或待核验期间保留，完整确认后清理并留下去重记录。临时媒体受到下载、时长和缓存限制，详见[ASR](asr.md)。

## 来源与网络保护

网页、媒体、字幕、分享文案、模型输出和远端错误均是不可信数据。它们不能改变命令、保存位置、授权或本机文件读取范围。不读取浏览器 Cookie、不登录平台、不绕过验证码，不扫描本机找字幕。

来源、每次跳转、内容 ID 和媒体地址分别核验。默认系统 DNS；只有系统返回全部位于 `198.18.0.0/15` 的代理假地址，且用户已启用 `configure --public-dns on` 时，才用固定 Cloudflare TLS 地址重新核验。仍要求公网 IP、有效 TLS、允许域名和同条来源，不能把它改成通用私网访问开关。`configure --public-dns off` 可恢复默认。

模型／ASR 预检不调用模型、不下载权重、不验证登录和额度。`check` 访问 Notion 只读核验，必要时受信程序可能更新本地授权记录。真实模型调用消耗现有服务用量，不静默切换额外付费服务。

## 停止、身份与分发

“暂停收集”暂停队列；“断开 Notion”清除本地连接。都保留任务和已存笔记。完整撤销在 Notion 连接设置操作。秘密若误贴到聊天，应从相应服务撤销，不以删除回复代替。

只允许安装者本人已认证的私人对话；飞书沿用 Hermes 配对与身份限制，不自动放开陌生人或群聊。多用户共享一套电脑账户不属于本版隔离范围。

发布包仅含白名单代码、文档和依赖清单，不含授权、个人状态、原始媒体、权重、聊天或转写验收材料。本次按用户要求上传测试候选版；公开上传不代表真实视频流程已验收通过。
