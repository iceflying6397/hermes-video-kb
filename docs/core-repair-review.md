# 2.1.0 核心回退修复与复审

2026-09-28，测试候选版，供用户安装实测。**代码已接回三处断点，完整真实流程尚未验收通过，不能报告整个修复已完成。**

原版是给 Hermes 执行的 Skill。它要求宿主取得原生字幕、公开页面数据、浏览器可见内容或媒体，再调用可用转写并整理保存。“仓库没有独立转写脚本”不说明它没有转写能力；此前相反判断已撤回。

## 功能对照与最小方案

| 环节 | 原版 | 2.0.1 回退 | 本轮修改与边界 |
|---|---|---|---|
| 分享入口 | 宿主从分享文字提取来源并跟随平台跳转 | 入口拒绝用户使用的 `xhslink.cn/o/` | 单 URL 和分享文字进入同一校验；保留获取所需参数，最终内容 ID 固定，拒绝混淆域名、异源和换内容跳转 |
| 视频真实文字 | 字幕优先；公开媒体加本地或已有 ASR | 固定程序没有媒体获取和转写 | 从对应 note ID／aweme ID 的公开数据发现 MP4／M4A，受限下载、解码、离线 ASR；代码接通，真实主样例仍待验收 |
| 模型整理 | 当前 Hermes 模型可驱动整理 | 仅允许两类 API 协议，排除 GPT 订阅 | 预检和实际请求均复用 Hermes 原生 Codex Responses 适配器；无模型工具，不买 API、不转发订阅令牌到代理 |
| Notion | 原版使用用户提供的 Integration 密钥 | 新版改用官方 OAuth，有专用绑定和恢复措施 | 保留官方 OAuth 和固定操作，新增完整正文回读；不能只凭页面、父级和去重标记报告成功 |
| 中断和重试 | 指令要求持久保存并续接 | 固定队列已有部分保护 | 转写在调用摘要前落盘；已知候选页面只读恢复；别名跟随原任务；旧任务和笔记不删除、不重新建库 |

选择小型适配而非整体回退：保留经过检查的安装、队列和 Notion 限定操作，恢复缺失的媒体与订阅分支。来源文字始终留在无工具的整理链路，不送回操作型智能体执行。无需作者服务器，也不改变 Hermes 全局审批。

本轮仍未接回原版全部路线：没有浏览器渲染／资源发现后备、HLS／DASH、OCR、平台登录或验证码处理。抖音、小红书和公众号的实现与实测范围分别列于[平台范围](supported-platforms.md)。这些是具体限制，不能将它们包装成所有公开视频均可处理。

## 安全与方便程度复审

- 来源和媒体分别核验，媒体只从匹配本条内容的对象选取。每次跳转重新校验域名和公网地址，TLS 校验和固定 IP 连接保留。媒体不会作为可执行命令。
- 本地 ASR 使用现成缓存权重，无云端自动回退；运行组件可经说明后由安装器一次准备。缺少组件或识别失败时任务可重试，不把这类失败锁定成“已完成书签”。
- 媒体限制为 256 MB、20 分钟；下载 3 分钟、解码 90 秒、ASR 5 分钟；识别使用 2 个 CPU 线程。自身媒体缓存有 640 MB 上限和带所有权标记的中断清理。没有无限并发或无限重试。
- 特定代理的假 IP 恢复默认关闭。用户允许后，仅系统答案全部属于 `198.18.0.0/15` 时向固定 Cloudflare 加密 DNS 查询公开域名；不发送路径、分享参数、正文或凭据。结果仍须是公网地址并固定连接，不关闭内网保护。
- GPT 订阅调用由 Hermes 原生凭据解析器和 Responses 适配器内部处理；官方目标限定、禁止重定向和隐式代理。登录失效、额度或临时不可用保留正文，不静默切换付费 API。
- Notion 保存和恢复必须对照本地原稿核验全部段落。返回属性但没有正文、丢中段／尾部、明确截断均保留待核实，不重复创建，也不清除原稿。旧未知任务如果已经缺少原稿，只能如实保留未核实。
- 别名去重继承原笔记的证据状态，不能把本次未写入的转写说成已经保存。旧书签不会因为重复发送就被默默改写。
- 正常链接收集不逐条索要授权；新增下载、数据接收方和真实账户验收需具体说明。官方 Notion 权限可能覆盖工作区其他内容；固定程序限制、普通文件权限和 Skill 指令都不等于操作系统沙箱。

独立复审发现并修正了完整正文核验缺失、摘要前原稿未持久保存、别名证据误报、别名恢复提示、多媒体时长不匹配、特殊媒体文件误删风险及中断缓存增长问题。未发现这些测试覆盖范围内的新增秘密泄露链路，不作绝对安全保证。

## 验证如何解释

隔离测试包含真正执行 Hermes 原生适配器但使用合成凭据和受控网络响应的集成测试。它证明协议路径已经接通，不证明真实账户可用。基线旧版测试同样曾全部通过，因此测试数量不能替代真实视频验收。

本机真实只读预检、公开短链首跳、实际媒体解码，与尚未执行的 ASR／订阅请求／Notion 写入，均在[验收状态](acceptance-status.md)分开说明。新增可选依赖通过官方 PyPI 固定版本及哈希核查、OSV 已知公告查询；未命中不代表没有未知漏洞，跨平台元数据也不等于各平台实机测试。
