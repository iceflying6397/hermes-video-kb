# 知识库内容

首次官方连接后，核验并复用有效绑定，或自动建立专用知识库。用户不需要手动建字段、查数据库编号或把名称当作唯一身份。

固定属性包括名称、来源链接、平台、内容状态和去重标记。页面正文包含摘要、关键观点、可行动项、内容状态／可靠性，以及真实来源文本或转写。只有标题、简介等低证据内容时明确标为待复核，不编造正文。

本轮已接回受限媒体获取和本地 ASR。转写标注“机器转写、非官方字幕”，覆盖不足或截断如实说明。手工提供字幕可以形成独立补充，不能替代自动视频验收。

摘要失败时正文留在本机，尚不创建仅原文笔记；之后可续处理。写后回读与本地原稿逐行比较完整摘要、观点、可靠性和正文，不能只确认页面存在。远端正文未取全时保留待确认和原稿，不盲目重建；确认完整保存后清理本机正文。

重复来源返回原笔记。旧版本已保存内容不会自动补摘要或被改写；重复链接不能把新取得但未保存的文字冒充为旧页面内容。队列、绑定和保存目标由固定流程维护，不通过删除状态解决冲突。
