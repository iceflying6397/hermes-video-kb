# 平台与模型范围

2.1.0 是测试候选版，完整真实流程尚未验收通过。下面列的是实际实现，平台页面变化、反爬和运行环境仍可能导致失败。当前验证结果以[验收状态](acceptance-status.md)为准。

| 来源 | 已实现路径 | 边界与未验证部分 |
|---|---|---|
| 小红书 | `xhslink.cn/o/...`、常用分享短链和正式笔记地址；按 note ID 取公开文字／文字稿／MP4 媒体，再本地 ASR | 历史真实链接需重新验收；无浏览器渲染后备、OCR、登录或验证码处理 |
| 抖音 | 分享短链、正式视频／笔记地址；按 aweme ID 读取公开页面数据、文字稿或允许域名的 MP4，再本地 ASR | 未证明全部页面数据和 CDN 形式可用；真实平台视频逐项待验收 |
| 微信公众号 | 公开文章正文、摘要和来源保存 | 不转写文章内嵌视频；删除、登录限制和风控内容不保证可读 |
| 其他平台 | 暂无 | 不宣称支持 B 站、YouTube、视频号、快手或任意媒体地址 |

媒体仅支持受限的 MP4／M4A 直连；HLS／DASH 和浏览器资源发现尚未实现。只有简介、标题或配文时如实降级，不能当成视频正文。没有媒体处理条件时保留任务，不要求用户把手工字幕作为日常输入。

摘要接入支持静态可确定的 Chat Completions、Anthropic Messages，以及 Hermes 原生 `openai-codex / codex_responses` 订阅。订阅令牌由宿主原生程序内部使用，只发往 ChatGPT 官方目标；不向第三方代理转发，不静默换成收费 API。其他 Responses、`auto`、外部进程模式未承诺支持。

`doctor` 检查模型与本地 ASR 条件，不调用模型、不验证登录有效性或额度。实际登录、整理、转写与写入需分别验收。自动安装面向 macOS、Linux；本轮实际开发环境为 macOS，Linux 未实机验证，Windows 暂不支持。未承诺兼容所有 Hermes 版本。
