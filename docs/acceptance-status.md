## 受控／模拟验证

- 单 URL 与整段小红书分享文案、必要参数保留、来源身份、恶意域名、换内容跳转、私网阻断和 fake-IP 限定恢复。
- 无原生字幕时从匹配对象选取媒体并调用下载／解码／ASR 分支；该类测试的媒体与识别输出使用受控替身，不能算真实转写。
- 真 Hermes 源码、真 SDK、合成凭据及受控 SSE，完成原生 Responses 请求和结果转换；无真实账户调用。
- Notion 完整正文、中段、尾部、摘要和观点顺序的校验；只返回页面或标记、缺正文、截断、回包丢失、错误账号／父级均不能误报成功。
- 摘要中断保留原稿、别名去重与恢复、旧无原稿未知任务保留；安装并发、未知 Skill／用户修改保护及强制中断恢复。
- 可选 ASR 安装方案在受控依赖安装器中验证，含组件选择继承、核心版升级、Python 版本预检和失败回滚。

固定可选依赖共 29 个包，当前 macOS arm64 / Python 3.12 对应 wheel 合计约 58.5 MB，模型权重不包含在内。已核对官方 PyPI 哈希和 OSV 已知公告，无命中。该锁中的 NumPy 要求 Python 3.12+；核心安装仍为 Python 3.11+。Linux、其他架构及旧 macOS 未实机验收。
