# 使用现有飞书入口

飞书是可选入口。已有 Hermes 和模型的用户可以先在当前对话安装、连接 Notion 并验收，不必为了处理视频新建飞书应用。

如果已连接飞书，使用安装者本人已配对的私人对话。沿用 Hermes 的身份校验和审批，不开放陌生人或群聊，也不允许他人代替本人批准。不要把视频、昵称或用户自报身份当作认证。

首次 Notion 授权在运行 Hermes 的电脑上完成；连接后可从手机飞书直接发送支持平台的公开链接或分享文案。正文获取、ASR、模型整理和保存能力仍以实际结果为准，连接飞书成功不能替代核心验收。

本轮不自动新增 Gateway、后台服务或其他会话，也不修改原模型设置。需要新增入口时另行说明具体影响。
